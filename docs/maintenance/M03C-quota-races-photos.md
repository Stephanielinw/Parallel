# Parallel Maintenance M03-C — 隔离容量/跨标签/照片一致性探针

**状态：仅测试环境的 Shadow Challenge；不启用 IndexedDB 主存档、不改生产数据、不执行用户备份恢复。**

## 实现范围

本阶段延续 M03-B 的独立测试数据库方案。由 CI 的 Playwright WebKit（390×844、触控仿真）注入测试脚本：

- `tests/fixtures/m03c-shadow-challenge.js`：对合成存档进行源指纹绑定、随机隔离数据库命名、源照片库只读核对和阶段性重验；
- `tests/fixtures/m03b-shadow-lab.js`：仅新增 `simulated-quota-abort` 故障注入，主动终止单事务并返回标记为 `QuotaExceededError` 的*模拟*错误；
- `e2e/m03c-storage-pressure-race.spec.ts`：三项真实 WebKit 浏览器测试；
- `tests/m03c-shadow-guard.test.cjs`：强制测试代码不得导入生产应用、不得写或删除旧存档、不得初始化丢失的源照片数据库；
- `.github/workflows/pages.yml` + `playwright.m02.config.ts`：加入已有发布门禁。

不更改 `public/parallel/offline.js`、`public/parallel/app.js`、`src/App.tsx`，不替换 `localStorage['parallel-portable-v2']`，不执行真实 iOS 数据迁移。M00 `archive/m00-baseline-20261122` 仍是代码恢复点，不是手机数据备份。

## 证明的三个场景

1. **模拟写入空间不足**：在已经提交的影子副本上发起下一次事务并主动 abort，验证旧提交可读、`localStorage` 原字节不变；对全新数据库 abort 后检查没有被标为已提交的快照。这个注入**不是 Safari 真正出现 QuotaExceededError**，不代表容量压力已解决。
2. **两个标签页争用存档**：标签 B 先捕获存档指纹，标签 A 更新旧主存档，再由 B 尝试复制；B 必须拒绝过期指纹。两个已经同步到同一源版本的标签页并发复制时，每次产生独立的随机实验数据库；彼此不覆盖，源仍由旧引擎管理。M03-C 新增对压缩/未压缩旧主存档的只读解码，若标签页内存引擎与最新源数据不一致，即使它重新捕获了最新存档指纹也会拒绝实验复制。**这仍不等于生产跨标签锁**：并行写入间的竞态、通知丢失和真机后台恢复需要正式迁移时另行验证。
3. **照片库与消息分离**：在独立测试上下文先写入合成照片，然后测试探针通过只读事务对比真实照片 IndexedDB `parallel-chat-photos-v1/photos` 与备份包内附件。如果源照片变更，即使文字影子副本仍可读，也拒绝将它声明为一致的完整候选。**两个数据库没有跨库原子事务**：复制前后重复验证只能发现部分竞争，不能保证源照片不会恰好在两次检查之间发生变化。实验也不清理或覆盖既有照片。

## 已知风险与正式上线门禁（继续阻止生产迁移）

- **真实 iPhone 备份**：尚无证据表明用户在两个独立位置保存并通过 M03-A 核验了*同一次导出*的完整 JSON。没有确认，不得迁移。
- **真实容量压力**：CI WebKit 不是 iOS Safari，模拟 quota abort 不代表实际设备低空间行为；需要合成大数据/写入放大与真机内存峰值、Safari 杀后台和存储回收验证。
- **原始数据与密钥**：M03-B/C 复制的是 `exportData()`，会剥离 API 密钥和少量独立存储细节。生产迁移必须单独制定完整原始存档与密钥处置协议，不能把实验备份当字节级的全部主存档。
- **真正多标签同步**：测试的旧 token 拦截并不替代持久版本号、写入序列化、跨标签通知、后台页面刷新或冲突用户界面。正式方案还要证明发生竞争时不会用较旧引擎缓存覆盖较新源数据。
- **照片原子性**：真实消息和照片当前分属 localStorage 与 IndexedDB。正式迁移必须制定照片事务与主存档提交的恢复策略、缺失附件报错、孤儿清理规则，并在真实 iOS 设备上验证。
- **正式切换、回滚与清理**：不能把 shadow copy 直接设为权威存储。未来应先保留旧主存档/两个独立完整备份，实施独立显式开关、校验、回滚及版本追踪。删除旧 key 是更远期、需要单独明确确认的操作。

以上结论仅对**合成数据**及一次性 Playwright 浏览器上下文成立。M03-C 完成不代表正式 IndexedDB 迁移已获批准。
