# Parallel v0.5 · 纯文字照片、60 秒短信合批与自有 Elsewhere 预设

这是一个**独立的本地 Web App 原型**，而不是原生 iOS App。它没有修改 Elsewhere 仓库，也不会自动上传、分发或捆绑你的私人预设文件。所有 AI 候选来自本地已收录的同人角色目录，尚不能联网识别任意作品。

## 最快打开

在压缩包里找到 **`Parallel_v0.5_直接打开.html`**，双击后用 Chrome 或 Safari 打开。不需要 Python 或安装软件。单 HTML 版的 Profile、聊天、预设存在当前浏览器的 localStorage；在「终端 → 连接与模型 → 存档备份」可导出 JSON。**不同 HTML 文件名/路径与不同浏览器之间不保证自动继承旧存档，请先从旧版导出备份。**

如果模型服务的 CORS 阻止浏览器直连，可以使用项目的 Python 服务版：

```sh
cd parallel_ai_date
python3 server.py
```

打开 `http://127.0.0.1:8765/`。Python 版本需要 3.10+，只用标准库，服务器只绑定本机回环地址。API Key 存在 `data/connection.json`，尝试设置 `0600` 权限；单 HTML 版的 Key 则以明文储存在浏览器本地，**不建议在共享设备使用**。不要把服务版 `data/` 文件夹上传或分享。

## 本次更新

**1. 发现页留白、照片只使用文字。** 约会卡片的照片区域为空白；点空白区会弹出人物的照片文字描写。无 API 时使用稳定的示例描述（不是经过图像验证的真实照片），连接文字模型后可在弹窗主动要求生成更详细的描写。没有自动生图、图片模型设置或 `/images/generations` 调用；用户自己的 Profile 头像上传仍然保留。

**2. 手机聊天使用 60 秒静默合批。** 每条新短信在当前角色的对话里立即保存并显示，重新启动 60 秒倒计时；安静满 60 秒后，将本轮的短信历史合并成**一次**模型请求。点击「让角色继续回复」可提前完成这一轮。请求失败时保留待处理短信，用户可手动重试；批次发出后又来的消息排入下一轮。同一个角色、不同 Profile 分开计时；切换到见面模式会取消尚未生成的短信回复，但**不删已发短信**，可以立即使用小说模式接续。浏览器关闭时**没有**后台任务；再次打开聊天时会检查到期队列。此实现是 Parallel 的独立精简调度器，不等于直接复用了 Elsewhere 所有已上线的超时/迟到隔离细节。

**3.「小狗乐园」自有预设格式适配。** 在「终端 → 文字预设 → 导入 JSON」选择你自己保管的《小狗乐园.json》（`format: elsewhere-preset`, `schemaVersion: 1`）。导入前可选择「追加」或「替换涉及模式」，推荐 **替换涉及模式**，这样只替换面对面小说的默认条目、不会改动手机聊天条目。导入保留正文、条目顺序、`system` / `user` / `assistant` role 和启停状态，并将原有 group 作为标题前缀显示。实际生成 Prompt 时，`{{user}}` 替换为当前扮演 Profile 姓名，`{{char}}` 替换为当前 AI 角色姓名。导入源文件不会修改。不会捆绑你的私有预设，也不提供受限第三方预设转换器。

**4. 独立导出继续可用。** 在「手机聊天」或「面对面小说」标签下点「导出当前模式」，得到对应模式的 Parallel 自有 JSON；「导出全部」包含两种模式。导出的只是条目及其顺序、role、正文和开关，没有 API Key 或聊天记录。已经导入的 Elsewhere 格式在 Parallel 内导出时变成 Parallel 自有格式，不是对 Elsewhere 原 JSON 的字节级还原。

## 其他保留功能

- 四栏：Profile、发现、消息、终端；支持多 Profile、可自由输入作品来源 Tag、左拒绝右喜欢、十位候选刷新。
- 同一原作时期 AI 角色重复刷到继续保留经历；同名不同版本（RE2、RE6 等）独立。玩家扮演的同版本角色不能匹配自己；玩家角色与 AI 角色的记忆不共享。
- 每个角色聊天窗顶部仍有「进入见面／返回聊天」，只影响**之后**的输出，旧短信、旧小说段落的布局不变。聊天与线下保有同一关系事件轨迹。
- OpenAI-compatible Base URL、API Key、模型列表、温度、Top P 和 Max tokens。小狗乐园的 600–1200 字小说目标建议在终端把 Max tokens 设为 **2400–3500**；模型不一定严格满足字数和全部指令。

## 测试

```sh
python3 -m unittest discover -s tests -v
node tests/test_portable.cjs
```

本次检查包含：自有 Elsewhere 预设导入、启停与 role、宏替换、完整 60 秒静默期前后合批、手动发送、模式切换取消未回复批次、用户历史不丢、无图照片描述、单文件版数据流程，以及 390px 宽的浏览器界面。**真实付费 API 兼容性仍需按你使用的模型实测**；单 HTML 版可能受 CORS 限制。
